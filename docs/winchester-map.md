# Winchester map source

The grayscale map in `assets/images/winchester-map.svg` renders real OpenStreetMap building footprints, streets, parks and waterways for Winchester, Hampshire, UK. Retrieved 2026-11-10 using the Overpass API at https://overpass-api.de/api/interpreter.

Map bounds (west, south, east, north): `-1.329, 51.0588, -1.299, 51.0696`. North is up. It is a cartographic rendering, not aerial photography. The emotional routes and four interactive markers remain the existing artistic overlay and are not a GPS record or geocoded location claims.

## Expressive motion

The red particles flow in both directions along the artwork route, drift through nearby space, and gather around a focused location. Their radius and motion vary with the existing categorical mood log: neutral is calmer, good is moderate and anxious is more restless. These are artistic mappings of the recorded categories, not measured numeric mood scores. Pausing freezes automatic motion; reduced-motion settings start the view paused. The four labels follow the author’s annotated composition rather than geocoded coordinates.
